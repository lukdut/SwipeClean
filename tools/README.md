# Тестовая галерея эмулятора

Описание локальной модели, истории решений и персональной сортировки:
[PHOTO_RANKING.md](PHOTO_RANKING.md).

Модель скачивается приложением при первом анализе. Для сборки ONNX-файл не нужен.
Для инструментальных тестов с реальным энкодером подготовьте локальный файл:

```sh
python3 tools/fetch_embedding_model.py
```

Он сохраняется в `build/model-fixtures/` и включается только в тестовый APK.

Из корня проекта:

```sh
python3 tools/seed_emulator_gallery.py --serial emulator-5554
```

Нужны Python 3, curl и запущенный эмулятор. Скрипт находит `adb` в `PATH` или через
`sdk.dir` в `local.properties`; также можно передать `--adb /путь/к/adb`.

В альбом `Pictures/SwipeCleanDemo` добавляются 40 изображений:

- 24 фотографии природы, животных, города и еды;
- 8 размытых вариантов, полученных с сервера изображений;
- 8 программно созданных тестовых кадров: тёмные, пересвеченные, однотонные и с плавными границами.

Фотографии скачиваются из [Unsplash](https://unsplash.com/license).
Конкретные URL сохраняются в `build/emulator-gallery/sources.json`, а файлы —
в `build/emulator-gallery/images`. Эта папка исключена из Git.
Повторный запуск использует локальный кэш и те же имена файлов.
Скрипт проверяет, что выбранное устройство — эмулятор.

После загрузки перезапустите SwipeClean. В настройках можно сбросить прогресс
просмотра, затем вручную запустить анализ и выбрать сортировку «Неудачные».
Тестовые кадры помогают проверить признаки качества; подборка не является
размеченным набором для измерения точности алгоритма.
